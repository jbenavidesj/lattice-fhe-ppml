# RNS-BFV parameter candidates

This file records the candidate arithmetic parameters used in the current Paper 1 design discussion. They are **computational candidates**, not a security parameter selection.

## Ring and plaintext parameters

- Ring dimension: (N=8192).
- Cyclotomic polynomial: (X^N+1) (negacyclic ring).
- Plaintext modulus candidate: (t=65537).
- Four pairwise-coprime coefficient moduli are proposed.

| Modulus | Candidate (q_i) | (w) | (delta_i=2^w-q_i) | Candidate (psi_i) |
|---|---:|---:|---:|---:|
| (q_1) | 36028797002170369 | 55 | 16793599 | 22505317672356688 |
| (q_2) | 36028796951838721 | 55 | 67125247 | 29410112198941026 |
| (q_3) | 18014398508400641 | 54 | 1081343 | 9354911369072846 |
| (q_4) | 18014398507892737 | 54 | 1589247 | 12617745759101472 |

The design record reports that each (q_i) is prime, (q_i\equiv1\pmod{2N}), and each (psi_i) has exact order (2N=16384), so that (psi_i^N\equiv-1\pmod{q_i}). These claims must be regenerated by a checked-in audit script and retained output before publication.

## Aggregate modulus

For (Q=\prod_iq_i), the recorded value is approximately (2^{218}) (bit length 218). With (Delta=\lfloor Q/t\rfloor), the recorded approximation is (log_2\Delta\approx201.99998).

These values alone do **not** establish an RLWE security level. Security estimation requires, at minimum, the exact ring, modulus chain, secret distribution, error distribution and sampler details, and the attack estimator/version and cost model.

## AsymRed candidate conditions

For each modulus represented as (q=2^w-\delta), the proposed reduction requires
(1\leq\delta<2^{\lfloor w/2\rfloor}), and the input is restricted to (0\leq z<q^2).

Let (B=2^w), (h=\lfloor w/2\rfloor), and split
(z=z_HB+z_L). Define
(u=z_H\delta+z_L), then split (u=u_HB+u_L), and set
(v=u_H\delta+u_L). The construction gives (v\equiv z\pmod q); the implementation must prove the stated range bound (recorded target: (0\leq v<2q)) before relying on one conditional subtraction to obtain the canonical residue.

Implementation review must check integer widths and overflow at every intermediate operation. For the current 54/55-bit candidates, a 128-bit intermediate type is intended; this is not a substitute for compiler-level and boundary testing.

## Required reproducibility artifacts

- parameter-generation/audit script;
- exact primality and root-order test output;
- fixed test vectors including boundary values;
- independent differential tests against arbitrary-precision arithmetic;
- tool versions and deterministic seeds.

Do not change these candidates silently. Any parameter change requires regenerating roots, aggregate modulus values, correctness bounds, and the security estimate.
